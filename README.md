# Week 3 - Fibonacci Series

A Python program to print the Fibonacci series for n terms.

## Description

The Fibonacci series is a sequence where each number is the sum of the two preceding ones. The sequence starts with 0 and 1.

**Example:** For 7 terms: `0 1 1 2 3 5 8`

## Requirements

- Python 3 installed

## How to Run

1. Open the folder in a terminal.
2. Run the program:

   ```
   python fibonnaci.py
   ```

3. Enter the number of terms when prompted.

## Example

**Input:**

```
Enter the number of terms: 7
```

**Output:**

```
Fibonacci Series:
0 1 1 2 3 5 8
```
